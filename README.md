# 머니플로우

원화·캐나다 달러 계좌의 입금, 송금, 지출을 기록하는 간단한 돈 관리 앱입니다. 서버 없이 브라우저에서만 동작하며, 데이터는 이 기기의 `localStorage`에 저장됩니다.

## 기능

- 하단 탭: 대시보드, 계좌, 지출계획, 설정
- 대시보드: 전체 총 금액, 원화/캐나다 달러 잔액, 입금·송금·지출 통계
- 지출계획 탭: 사유별 계획 확인 현황
- 계좌 목록에서 입금 / 송금 / 지출
- 설정: 계좌 추가, 사유, 계획 설정, 수정 모드, JSON 내보내기/복원
- 계좌 편집 / 삭제 (이름, 원화 또는 캐나다 달러)
- 입금(수입), 송금, 지출: 금액과 미리 정한 사유를 드롭다운으로 선택
- 지출계획: 사유별 출금 계좌, 금액, 예정 날짜 지정, 지출 또는 송금으로 확인
- 송금 시 통화가 다르면 `1 CAD = ? KRW` 환율로 환전
- 사유 목록 추가/삭제

## 로컬에서 보기

```bash
python3 -m http.server 8080
```

브라우저에서 `http://localhost:8080`을 엽니다.

## GitHub Pages

1. GitHub 저장소 **Settings → Pages**
2. **Source**를 **GitHub Actions**로 선택
3. `main` 브랜치에 푸시하면 `.github/workflows/pages.yml`이 배포합니다

주소는 보통 `https://<사용자이름>.github.io/moneyflow2/` 입니다.
